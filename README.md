# BMI Calculator

A small BMI calculator I made in C++ in 2018. It takes your weight in kilograms and your height in metres.

## Run it

You can get the [original Windows build](https://github.com/shashika-mora/bmi-cpp/releases/tag/v1.0) or compile the source with g++.

```powershell
g++ -std=c++11 "BMI Calculator.cpp" -o bmi-calculator.exe
.\bmi-calculator.exe
```
